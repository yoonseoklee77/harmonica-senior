# 하모니카 연습곡 페이지

어르신 수강생이 휴대폰으로 연습 음원을 듣는 페이지입니다.

## 새 곡 올리는 법

1. **mp3 올리기**: 위 목록에서 `mp3` 폴더를 누릅니다 → 오른쪽 위 **Add file → Upload files** → mp3 파일을 끌어다 놓습니다 → 아래 초록색 **Commit changes** 버튼을 누릅니다.
2. **곡 목록에 추가**: `songs.txt`를 누릅니다 → 오른쪽 위 **연필 모양(✏️)** 버튼 → `곡 목록` 줄 바로 아래에 아래처럼 적습니다 → **Commit changes**.

```
제목: 아리랑
날짜: 2026.11.16
메모: 첫 음을 길게 불어 주세요.
연주: 06-아리랑.mp3
반주: 06-아리랑-반주.mp3
```

3. 1~2분 뒤 휴대폰에서 페이지를 다시 열면 새 곡이 맨 위에 보입니다.

## 알아두기

- 곡과 곡 사이는 **빈 줄 하나**로 나눕니다.
- `연주:`, `반주:` 뒤의 파일 이름은 mp3 폴더에 올린 이름과 **글자 하나까지 똑같아야** 합니다. 다르면 화면에 "음원 파일을 찾을 수 없습니다"가 나옵니다.
- 메모가 필요 없으면 `메모:` 줄을 빼면 됩니다. 반주나 느린 연주도 없으면 그 줄을 빼면 됩니다.
- 번호는 자동으로 매겨지고, 날짜가 2주 이내인 곡에는 '새 곡' 표시가 자동으로 붙습니다.
- 맨 위의 `교실이름`, `페이지제목`, `안내` 문구도 같은 방법으로 고칠 수 있습니다.
- `index.html`은 고치지 않아도 됩니다.
